# 🏰 Tower Defense — Unity Pet Project

Некоммерческий учебный проект в жанре **Tower Defense**, разработанный с акцентом на чистую архитектуру, масштабируемость и использование ключевых паттернов проектирования в Unity.

> **Цель проекта:** Отработать построение гибкой и слабосвязанной игровой архитектуры с помощью кастомного Dependency Injection и фундаментальных асинхронных механизмов Unity.

## 🛠 Стек технологий и инструментов

* **Engine:** Unity
* **Language:** C#
* **Architecture & Patterns:** 
  * **Custom DI Container** — самописный инжектор зависимостей для устранения жестких связей между компонентами.
  * **State Machine** — управление состояниями AI врагов и глобальным игровым циклом.
  * **Factory, Facade, Composition, Provider** — основные порождающие и структурные паттерны.
* **Async & Asset Management:** Coroutines, Resources
* **IDE & VCS:** JetBrains Rider, Git / GitHub

## 🏗 Архитектура и ключевые системы

* **Внедрение зависимостей (Custom DI):** Все сервисы и системы связываются через легкий собственный DI-контейнер без использования тяжелых сторонних фреймворков.
* **Игровой цикл (Game Loop):** Построен на базе **State Machine** (Инициализация -> Загрузка ресурсов -> Спавн волн -> Геймплей -> Победа/Поражение).
* **Искусственный интеллект (AI):** Поведение и логика перемещения врагов организованы с помощью иерархических состояний (**Finite State Machine**).
* **Менеджмент ресурсов:** Загрузка и управление жизненным циклом ассетов (префабы, конфиги) реализованы через модуль **Resources** и асинхронные корутины (**Coroutines**).
* **Система сохранений:** Реализован абстрактный провайдер сохранений (Provider Pattern) для удобной смены источника данных (PlayerPrefs / JSON).
* **Боевая система:** Спавн волн, атака башен, расчет урона и попаданий реализованы через комбинацию паттернов **Factory** и **Composition**.
